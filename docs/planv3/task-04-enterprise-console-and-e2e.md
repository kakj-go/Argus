# PlanV3 Task 04：企业控制台与端到端验收

## 目标

在组织与权限 → 远程访问下提供四个一致的配置 Tab，并让管理员能够理解、模拟、编辑、停用、恢复和审计远程访问配置。

## 页面结构

~~~text
组织与权限
└── 远程访问
    ├── 访问授权
    ├── 访问规则
    ├── 审批流程
    └── 会话策略
~~~

运行态入口单独展示访问申请、待审批、活动会话、历史会话和录像；企业控制台当前只验收桌面端，移动端不属于本版本目标。

## E2E 核心场景

1. 创建 Grant、Rule、Workflow、Session Profile，并在模拟器看到预期决策。
2. 生产 SSH 访问命中 MFA + 双人审批，申请人无法自批。
3. 审批完成后只能获得绑定目标、账号、协议和版本的 Lease。
4. 停用 Grant 立即撤销 Lease 并终止活动会话。
5. 停用 Workflow 不影响已有申请快照；停用 Profile 不改变已有 Session。
6. 规则版本冲突不会覆盖其他管理员的修改。
7. 录像读取、命令审计和配置变更均可追溯到企业用户和版本。
8. 测试失败也清理临时 Namespace、PVC、Topic、Bucket、Lease 和测试凭据。
