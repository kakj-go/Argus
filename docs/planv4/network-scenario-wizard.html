场景速查表（弹框卡片与这里的行一一对应）

网络场景 网络条件 接入方式（控制面） 指标回传（数据面） 远程终端 状态
① 独立主机 · 双向可达 Argus 可 SSH 到主机，主机可出站访问 Argus Direct Executor SSH 安装/管理 Collector 直推 ingest（direct_argus） 支持（Executor PTY） 已支持
② 独立主机 · 只进不出 Argus 可 SSH 到主机，主机无法出站 Direct Executor SSH 安装/管理 Executor 建立反向隧道，Collector 推本机端口回传 支持（Executor PTY） 规划中
③ 堡垒机成员 · 连不上堡垒机端口 我们不可直达成员；堡垒机可出站、可 SSH 成员；成员连堡垒机 OTLP 端口不通 堡垒机 Connector SSH 安装/管理 堡垒机向成员建反向隧道 → 成员推本机端口 → 堡垒机 Gateway → Argus 支持（Connector 会话流） 规划中
④ 堡垒机无出站 · 仅可被 SSH 进入 Argus 可 SSH 进堡垒机；堡垒机与成员都无出站 Executor SSH 进堡垒机，反向隧道承载 Connector 控制通道 双层隧道：成员 ←隧道→ 堡垒机 Gateway ←隧道→ Argus 支持（隧道内 Connector 会话流） 暂缓 · 罕见
⑤ 只出不进 · 自助安装命令 Argus 不可达主机，主机可出站访问 Argus 用户在目标机执行一次性安装命令，自注册（self_enrolled） Collector 直推 ingest（direct_argus） 第一版不支持（无回路通道） 规划中
— 标准堡垒机（现有模式） 堡垒机可出站访问 Argus，成员可达堡垒机 一次性安装命令注册 Connector，出站长连接 成员 → 堡垒机 Gateway → Argus（bastion_gateway） 支持（Connector 会话流） 已支持
— 双向完全不通 无任何一方可以发起连接 无路径可达，任何监控系统都无法接入；需要先提供至少一条单向可达（多数情况是部署一台可出站堡垒机） 不可行
历史记录：本表曾把场景④理解为需要双层隧道并建议暂缓。该结论已被 Task 06 替代：堡垒机模式 C 复用 Executor SSH remote forward 承载 Connector 控制通道，属于正式交付和 E2E 验收范围。
